# Tool Oumijia v0.6.0 — EPLAN 2026 (Script Edition)

> **Bản dành cho EPLAN Education 2026.0.3, Script Edition.** Không kèm Add-in DLL.
> Các bản EPLAN 2026 khác và các phiên bản EPLAN khác chưa UAT; installer từ chối cài.

## Nội dung

- Nhóm ribbon **Quản lý EDZ**: `Nhập EDZ` → `Xuất EDZ` → `Menu bar`.
- Nhóm **Eplan Cloud** sao chép bảy command native của EPLAN, gồm **Data Portal**.
  Không mở `DataPortalTabView` riêng, không dùng WebView2/PortalHost, không lưu credential.
- `Nhập EDZ` / `Xuất EDZ` dùng shared runtime `Oumijia.EplanUi` / `Oumijia.EdzReader`
  trong `script\portal\`; không ghi Parts Database trong UAT.
- Script tự nạp lại mỗi lần EPLAN khởi động qua `STATION.EplanEplApiScriptGui.Scripts`.

## Vì sao chỉ có Script Edition

Add-in 2026 mới chỉ compile-check, chưa chạy runtime; Script Edition mới là bản
đã GUI UAT trên Education 2026.0.3. Vì vậy gói này chỉ phát hành edition đã kiểm chứng,
không đóng gói DLL Add-in chưa UAT. Máy build hiện tại không có EPLAN 2026 API để
tái tạo DLL Add-in net481.

## Cài đặt

1. Đóng tất cả EPLAN.
2. Giải nén ZIP, mở PowerShell tại thư mục gói.
3. Kiểm tra target:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Tool-Oumijia.ps1 -ListInstalled
   ```
4. Cài đúng target:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Tool-Oumijia.ps1 `
     -TargetW3u 'C:\Program Files\EPLAN\Education\2026.0.3\Bin\W3u.exe'
   ```
5. Mở EPLAN, kiểm tra ribbon và Data Portal. Đăng nhập Data Portal do người dùng tự thực hiện.

## UAT và giới hạn

| Hạng mục | Kết quả |
|---|---|
| Ribbon 3 nút EDZ + 7 command Cloud native | PASS trên Education 2026.0.3 (UAT trước) |
| Data Portal native mở/đóng/kéo/thả | PASS (UAT trước) |
| Form Nhập/Xuất EDZ mở/đóng, không ghi dữ liệu | PASS (UAT trước) |
| Nhập EDZ vào Parts Database test | Chưa chạy trong UAT này |
| Add-in runtime trên 2026 | Chưa UAT; không phát hành |
| EPLAN 2026 variant khác Education 2026.0.3 | Chưa UAT; installer từ chối |
| Installer headless trên máy 2026 thật | Chưa chạy lại trên máy build hiện tại |

Sau GUI UAT, chỉ chuỗi `ScriptVersion` được đổi thành `0.6.0-script.1`; hành vi runtime
không đổi. Bản bytes sau khi đổi version string chưa được UAT lại.

## Gói phát hành

- `script\`: Script Edition + `portal\` shared runtime net48.
- `docs\`: hướng dẫn và release notes.
- Root: installer/uninstaller thông minh, `EplanTargets.ps1`, `README.txt`, `VERSION.txt`, `SHA256.csv`.
- Không có `addin\`, `Oumijia.PortalHost`, `Microsoft.Web.WebView2*`, `WebView2Loader.dll`.
