# Tool Oumijia (EPLAN) v0.2.0

**Add-in EPLAN thật đầu tiên: Nhập/Xuất EDZ trực tiếp trong EPLAN qua API chính thức — cài 1 click, đã kiểm chứng end-to-end trên EPLAN Platform 2022.0.3.**

---

## ✨ Điểm chính v0.2.0

### 🧩 Add-in EPLAN — ribbon "Tool Oumijia" ⭐
- **Nhập EDZ…** — chọn file/thư mục → **batch import** tất cả gói `.edz` vào Parts Database
  qua API chính thức (`MDPartsManagement.ImportParts`, converter `IXPartsImportExportEdz`):
  - 3 chế độ nhập: *Chỉ thêm mới* / *Chỉ cập nhật* / *Cập nhật + thêm mới*
  - 3 cách nhận dạng part: *Mã hàng* / *UniqueId* / *UniqueId + mã hàng*
  - Tùy chọn nhập thêm ngôn ngữ phụ, log CSV kiểm toán từng đợt
- **Xuất EDZ…** — xuất parts ra EDZ qua `MDPartsDatabase.ExportParts` (converter EDZ của EPLAN):
  - Phạm vi: toàn bộ database đang mở **hoặc** các part đang chọn trong Parts Management
  - Cách xuất: 1 file duy nhất **hoặc** mỗi part 1 file (vào thư mục)
- **Cửa sổ Tool Oumijia** — mở app standalone ngay trong EPLAN
- Cài đặt **1 click** (`addin\Install-AddIn.bat`) — không cần Administrator, không cần đụng license EPLAN,
  gỡ cài đặt bằng `addin\Uninstall-AddIn.bat`

> Đã kiểm chứng đầy đủ trên **EPLAN Platform 2022.0.3**: EPLAN nạp add-in → tạo ribbon →
> gọi action từ command line → thoát sạch. Script đăng ký chạy headless 100% tự động.

### 🎯 Phạm vi EDZ-only (theo quyết định dự án)
- Tab Xuất & Nhập của app standalone giờ **chỉ xử lý `.edz`** — đơn giản, tập trung
- Add-in cũng chỉ nhập/xuất EDZ

### 🧪 Chất lượng
- Build sạch **0 warning**, **25/25 test pass**
- Bản release kèm sẵn thư mục `addin\` (DLL + installer + script) — không cần biên dịch

## ⚠️ Lưu ý khi dùng Nhập EDZ

- **Thử trên database test trước** khi nhập lô lớn vào database chính
  (Parts Management → chọn/tạo database test).
- Chế độ *Chỉ thêm mới* sẽ **bỏ qua** các part đã tồn tại — không phải lỗi.
- Nhật ký: `%APPDATA%\Tool Oumijia\logs\` (`addin.log`, `import-*.csv`, `export-*.csv`, `register-script.log`).
