# Tool Oumijia (EPLAN) v0.3.0

**"Add-in duy nhất" — bỏ hoàn toàn app exe; dialog Xuất EDZ mới chọn part bằng cây nhóm kiểu navigator EPLAN.**

---

## ✨ Điểm chính v0.3.0

### 📤 Xuất EDZ v2 — chọn part như EPLAN ⭐
- **Cây nhóm kiểu navigator**: Nhóm sản phẩm → nhóm → phân nhóm → hãng → part
  (vd `Electrical engineering → PLC → General → SIE → SIE.6ED1052-1HB00-0BA6 (LOGO! 24RC)`)
- **Tick chọn** từng part hoặc cả nhánh — checkbox 3 trạng thái (chọn / một phần / bỏ)
- **Tìm kiếm** theo mã hàng / tên / hãng; nút *Chọn tất cả / Bỏ chọn / Lấy từ Parts Management*
- **"Đã chọn: N part"** luôn hiển thị — biết chính xác sẽ xuất gì
- Xuất **1 file `parts.edz`** hoặc **mỗi part 1 file** — giống EPLAN

### 🧹 Bỏ hoàn toàn app exe (BREAKING)
- Chỉ còn **add-in trong EPLAN** (ribbon "Tool Oumijia" 2 nút: Nhập EDZ… / Xuất EDZ…)
- Gói release gọn nhẹ: **~26 KB** (thay vì 67 MB của bản app+add-in)

### 🐛 Sửa lỗi quan trọng
- **Registration bị "đè" bởi giá trị lịch sử**: nếu trước đó bạn từng đăng ký DLL bằng đường dẫn
  khác (vd dialog "API add-ins" trỏ vào bản giải nén), EPLAN vẫn nạp bản cũ dù installer chạy "OK".
  Script đăng ký mới **xóa key trước khi ghi + đọc lại xác nhận** — khắc phục triệt để.
- **Tên nhóm/tên part hiển thị đúng**: "Electrical engineering / PLC / General" thay vì mã số;
  "LOGO! 24RC" thay vì chuỗi đa ngôn ngữ trộn

### 🧪 Chẩn đoán & kiểm chứng
- Action `OumijiaDiagParts` (headless): mở parts database, đo tốc độ (647 part ~80 ms),
  tóm tắt cây nhóm, smoke-export 25 part ra EDZ
- Script chẩn đoán ribbon (`OumijiaRibbonDiag.cs`) và registration (`OumijiaReadReg.cs`)
- Đã kiểm chứng trọn pipeline trên EPLAN Platform 2022.0.3

| | |
|---|---|
| **File** | `Tool-Oumijia-AddIn-v0.3.0.zip` (~26 KB) |
