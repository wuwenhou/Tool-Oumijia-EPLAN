# Tool Oumijia (EPLAN) v0.5.0

**Script Edition — chạy không cần EPLAN API license (cho EPLAN mới chặn add-in chưa ký) + fix nhập EDZ & đích xuất.**

---

## ✨ Điểm chính v0.5.0

### 🆕 Script Edition — vượt rào license (theo issue #1)
- **Bản script C# 5** đầy đủ tính năng như add-in — chạy bằng **EPLAN Scripting** nên
  **KHÔNG cần API license, KHÔNG cần ký assembly**
  - Đã kiểm chứng trên **EPLAN Education 2026.0.3**: đọc 552 part, xuất EDZ thành công
  - Ribbon "Tool Oumijia" tự tạo khi khởi động (`OnMainStart`), script tự nạp lại mỗi lần mở EPLAN
- **Đăng ký tự nạp đáng tin cậy**: ghi trực tiếp danh sách `EplanEplApiScriptGui.Scripts`
  (action `RegisterScript` của EPLAN có bản không ghi gì — đã kiểm chứng và tránh bẫy)

### 🧠 Installer thông minh — không cần tự chọn bản
- `Install-Tool-Oumijia.bat`: thử bản **add-in** trước (đăng ký + self-test headless);
  nếu EPLAN vô hiệu hóa DLL (thiếu license) → **tự gỡ add-in + chuyển cài bản script** + kiểm chứng
- Gỡ cài cả hai bản bằng `Uninstall-Tool-Oumijia.bat`
- Gói zip chứa **cả hai bản**: `addin\` + `script\` + README chọn bản (kèm installer riêng)

### 🐛 Fix từ phản hồi người dùng
- **Nhập EDZ hết lỗi `S030060: Invalid scheme`**: tự dò field-mapping scheme
  (`PartsManagementGui.FieldMapping.LastUsed` → fallback `Standardvorgabe EPLAN` → tên từ thông báo lỗi).
  Đã kiểm chứng: `IMPORT SMOKE OK: 1 part re-imported (scheme='Standardvorgabe EPLAN')`
- **Đích xuất "Một file EDZ" gọn hơn**: chỉ chọn **thư mục**; tên file **tự động theo mã sản phẩm**
  (khi chọn 1 part) hoặc `parts.edz` (nhiều part); dòng xem trước "→ sẽ tạo: …"; hỏi ghi đè;
  nhớ thư mục cho lần sau — **áp dụng cho cả 2 bản**

## ⚠️ Lưu ý

- **EPLAN cũ (2022–2023)**: dùng bản **add-in** (installer tự chọn).
  Compiler script của các bản này thiếu reference `Eplan.EplApi.MasterData` nên bản script
  không compile được — không ảnh hưởng vì add-in đã chạy tốt.
- **EPLAN mới (2024+/2026) + không API license**: installer tự chuyển sang bản **script**.
- Thử **Nhập EDZ** trên database test trước khi nhập vào database chính.
- Nhật ký: `%APPDATA%\Tool Oumijia\logs\`.
