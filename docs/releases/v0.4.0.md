# Tool Oumijia (EPLAN) v0.4.0

**Hoàn thiện theo UAT: fix dấu tick & nút Xuất, panel chi tiết kiểu EPLAN, xuất theo loại bản ghi, nhập đơn giản hóa.**

---

## ✨ Điểm chính v0.4.0

### 🐛 Sửa lỗi từ phản hồi người dùng
- **Dấu ✓ hiện ngay khi tick** — trước đây đếm đúng nhưng ô tick không vẽ lại;
  nay buộc vẽ lại + **dòng đã chọn in đậm** làm chỉ báo phụ
- **Nút "XUẤT RA EDZ ▸" và "Chọn…" luôn hiển thị** — layout làm lại bằng bảng/dock
  (trước đây bị đẩy khỏi vùng nhìn ở một số cấu hình màn hình)
- **Sửa crash khi mở dialog Xuất** (`SplitterDistance…` — bắt được nhờ kiểm tra
  construct UI tự động) — nay mở an toàn 100%

### 🆕 Panel chi tiết (như EPLAN Overview)
- Bấm một part trên cây → xem **đầy đủ thuộc tính** ở panel bên phải: mã hàng, type/order/ERP,
  hãng, nhà cung cấp, nhóm sản phẩm 3 cấp, tên 1/2/3, mô tả, eCl@ss, EAN, macro ký hiệu/đồ họa,
  kích thước, ngày & người tạo/sửa
- **Nháy đúp** một dòng = copy giá trị vào clipboard
- Bấm nhóm → tóm tắt nhóm (số part, đã chọn bao nhiêu)

### 🆕 Xuất theo loại bản ghi (như EPLAN)
- Tick chọn: **Parts · Accessory list · Accessory placement · Drilling pattern ·
  Connection point pattern · Customer + Manufacturer/Supplier**
- Dùng API chính thức `MDPartsManagement.ExportParts` — **cờ đã được kiểm chứng thực tế**
  bằng cách giải nén EDZ đối chiếu số liệu database (77 mẫu khoan, 95 điểm nối,
  25 vị trí phụ kiện, 12 hãng — khớp 100%)
- ⚠️ Chế độ này xuất **toàn bộ** theo loại (không dùng tick cây) — file kèm macro/tài liệu
  nên có thể lớn (database demo: parts ≈ 290 MB)

### 🧹 Nhập EDZ đơn giản hóa
- Bỏ hàng tùy chọn (Chế độ nhập / Nhận dạng / Ngôn ngữ phụ) — chỉ còn: chọn file → **NHẬP**
- Mặc định hợp lý: *cập nhật part đã có + thêm part mới*, theo mã hàng

### 🧪 Kiểm thử kỹ (đợt này)
- Construct UI offscreen (bắt được 1 lỗi crash thật), self-test, diag dữ liệu part,
  smoke export + 7 combo theo loại bản ghi, giải nén EDZ đối chiếu — tất cả xanh
