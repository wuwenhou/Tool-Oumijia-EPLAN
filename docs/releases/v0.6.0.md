# Tool Oumijia (EPLAN) v0.6.0 — Data Portal native, bỏ WebView2

Phiên bản này bỏ hoàn toàn cửa sổ Data Portal WebView2 và chuyển nút **Data Portal** sang
**Data Portal native của EPLAN** (tab **Eplan Cloud**). Ribbon giữ đúng bốn lệnh:

```text
Nhập EDZ | Xuất EDZ | Data Portal | Menu bar
```

## Thay đổi chính

- **Data Portal native**: nút **Data Portal** gọi action `XDataPortalNavigatorToggle` của EPLAN,
  dùng đúng phiên EPLAN đã đăng nhập — không cần đăng nhập lại, không còn profile trình duyệt riêng.
- **Không còn WebView2/PortalHost**: xóa `Oumijia.PortalHost`, `Microsoft.Web.WebView2.*`,
  `WebView2Loader.dll`, profile `%APPDATA%\Tool Oumijia\WebView2` khỏi luồng cài đặt và gói phát hành.
- **Fallback rõ ràng**: nếu EPLAN không cung cấp action native hoặc action không thực thi được,
  Tool hiện thông báo và hướng dẫn mở trực tiếp **Eplan Cloud → Data Portal**, đồng thời ghi chi tiết
  vào `%APPDATA%\Tool Oumijia\logs\addin.log`.
- **Nâng cấp sạch**: installer và ribbon tự dọn command/DLL cũ (`Data Portal Web`, PortalHost,
  WebView2) khi cài đè bản 0.5.x; script 0.5.0 `Scripts\ToolOumijia.cs` được chuyển vào backups
  và mục đăng ký cũ được loại khỏi danh sách script tự nạp.
- **Giữ nguyên** Nhập EDZ, Xuất EDZ và shared runtime `Oumijia.EplanUi` / `Oumijia.EdzReader`.

## Quy trình tải và nhập EDZ

1. Bấm **Data Portal** trong ribbon Tool Oumijia (hoặc mở **Eplan Cloud → Data Portal**).
2. Tìm part và tải `.edz` theo quyền tài khoản EPLAN.
3. Mở **Tool Oumijia → Nhập EDZ**, chọn các file vừa tải, xem preview.
4. Nhập vào **database test** trước khi nhập database chính.

## Yêu cầu

- Windows 10/11 x64 và EPLAN Platform 2022 trở lên.
- Máy được IT cho phép kết nối EPLAN Data Portal bằng tài khoản hợp lệ.
- **Không cần** WebView2 Runtime.
- Không dùng phiên bản này để bỏ qua license, captcha hoặc điều khoản EPLAN.
- Nếu EPLAN không có action native, dùng trực tiếp **Eplan Cloud → Data Portal**.

## Gói phát hành

ZIP gồm Add-in và Script Edition, tài liệu và component dùng chung:

- `addin\`: `Oumijia.EplAddin.EDZ.dll` + `Oumijia.EplanUi.dll` + `Oumijia.EdzReader.dll` + SharpCompress.
- `script\`: Script Edition `0.6.0-script.1` + shared runtime trong `portal\`.
- Installer thông minh tự thử Add-in rồi chuyển sang Script Edition nếu EPLAN chặn DLL.

Hash của ZIP và DLL nằm trong `VERSION.txt` bên trong gói. SHA-256 của ZIP sẽ được dán vào
trang Release sau khi đóng gói bản cuối. Chưa tạo/tag Release cho đến khi kiểm thử thực tế
trong EPLAN đạt yêu cầu.

## Kiểm chứng

- Script C# 5 compile-check PASS với EPLAN 2026.0.3 (`csc /langversion:5`, EXIT=0).
- Add-in compile-check PASS với EPLAN 2026.0.3 Bin + shared runtime.
- Cần UAT sau khi restart EPLAN: ribbon 4 nút, Data Portal native mở đúng phiên, Nhập/Xuất EDZ
  không hồi quy, và thư mục `%APPDATA%\Tool Oumijia` không còn DLL WebView2/PortalHost.

## Chưa xác nhận

- Chưa xác nhận runtime nút Data Portal native trên máy đang mở EPLAN; cần đóng EPLAN và mở lại
  để nạp script/add-in mới.
- Chưa UAT trên mọi cấu hình DPI/workspace EPLAN.
