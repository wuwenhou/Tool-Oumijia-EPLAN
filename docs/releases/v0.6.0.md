# Tool Oumijia (EPLAN) v0.6.0

**Classic & Ecosystem — ribbon bốn nhóm, EPLAN Classic, VEE launcher.**

---

## ✨ Điểm chính v0.6.0

### Ribbon mới
Tab **Tool Oumijia** được sắp xếp thành bốn nhóm:

| Nhóm | Chức năng |
|---|---|
| **Quản lý EDZ** | Nhập EDZ…, Xuất EDZ… |
| **EPLAN Classic** | Mở cửa sổ tìm kiếm/lọc lệnh menu cũ; chỉ chạy action đã có |
| **VEE** | Gọi VEE Export connections / VEE Table Maker nếu người dùng đã tự cài |
| **GIRD** | Menu bar, Grid snap, Object snap, Grid visibility, Design mode, Align on grid |

## EPLAN Classic
- 12 nhóm đúng theo menu cũ: Project, Page, Layout space, Edit, View, Insert,
  Project data, Find, Options, Utilities, Window, Help.
- Ô tìm kiếm lọc theo tên/action.
- Lệnh chỉ chạy khi EPLAN có action tương ứng và action đó có thể được gọi;
  lệnh chưa xác minh hiển thị **"Không có trong phiên này"** và bị khóa.
- Không giả lập hoặc gọi action chưa rõ ý nghĩa/điều kiện.

## VEE — launcher, không phân phối
Tool Oumijia không chứa DLL/tài nguyên của các add-in sau:

- **VEE Export connections data** — gọi `VE_E_ExportConnections` nếu đã cài;
  nếu chưa có, mở hướng dẫn tải chính thức.
- **VEE Table Maker** — gọi `VEECreateEplanTable` nếu đã cài;
  nếu chưa có, mở hướng dẫn tải chính thức.
- **Show Menu Bar** — không cần cài để bật/tắt menu bar; Tool dùng action chính thức
  `MfToggleMainMenuAction` của EPLAN.
- Các tool chưa phát hành công khai (ví dụ Auto Update Report/Export PDF/Backup,
  VEE EDZ Killer) không được bọc vào release.

Gói release **không** chứa DLL, icon, logo hoặc tài nguyên của VIET EPLAN & ELECTRIC.
