## Thay đổi so với v0.6.0-2026

- Nhập EDZ có checkbox từng part (giống bản 2022); Status `Chọn: X/Y part`; nút nhập chỉ gửi part đã tick.
- `Oumijia.EdzReader`: đọc attribute XML part, dọn chuỗi đa ngôn ngữ, `PackageKey` từ manifest;
  thêm `EdzPackageFilter` (EDZ tạm cho phần đã chọn) và `SevenZipCopyWriter` (7z nội bộ, không cần 7-Zip).
- `Oumijia.EplanUi`: đồng bộ giao diện Nhập/Xuất qua `EdzDialogStyle`; nhãn cây `PARTNR (Tên)`; tooltips.
- Không thay đổi đăng ký ribbon/Cloud; không đụng tab Eplan Cloud gốc; không WebView2/PortalHost.

## Cài đặt

Đóng EPLAN; mở PowerShell trong thư mục gói:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Tool-Oumijia.ps1 -ListInstalled
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Tool-Oumijia.ps1 -TargetW3u 'C:\Program Files\EPLAN\Education\2026.0.3\Bin\W3u.exe'
```

Rollback: dùng bản v0.6.0-2026 (`gh release view v0.6.0`) nếu bản này lỗi trên máy bạn.
