# Tool Oumijia (EPLAN) v0.1.0

**Trợ lý quản lý gói dữ liệu linh kiện EPLAN (`.edz`) & macro (`.ema/.emp/.ems`) — quét, phân loại, xếp thư viện và cài đặt.**

---

## ✨ Điểm chính phiên bản đầu tiên

### 📦 Xuất (Export) — phân loại thư viện
- Quét thư mục inbox tìm `.edz` / `.ema` (nhiều thư mục, tùy chọn thư mục con)
- Đọc metadata **không cần EPLAN** — hỗ trợ cả container **ZIP lẫn 7z**
- Bảng chọn trực quan: Hãng / Nhóm / Mã hàng / đích đến (sửa được ngay trên bảng)
- Tự phân loại vào hơn **25 nhóm linh kiện** (MCB, MCCB, RCD, Contactor, Relay, PLC, PSU, Terminal, Sensor, Drive, Enclosure…)
- Xếp vào thư viện `Import/<Hãng>/<Nhóm>/`, chính sách trùng tên an toàn (mặc định không ghi đè)
- Log CSV đầy đủ + SHA-256; ghi nhớ đích đến bạn sửa tay

### 🧩 Nhập (Import)
- Cài macro `.ema/.emp/.ems` vào **thư mục master-data của EPLAN** (tự dò đường dẫn)
- Gom & kiểm tra danh sách EDZ để nhập vào Parts Database (batch import tự động qua EPLAN API nằm trong lộ trình v0.2)

### 🧪 Chất lượng
- **25+ test tự động** (đọc EDZ ZIP + 7z thật, classifier, library writer, integration với file mẫu)
- Build sạch **0 warning**, CI GitHub Actions, kèm 7 file EDZ mẫu tổng hợp để thử ngay
